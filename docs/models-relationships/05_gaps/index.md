# Gaps

This section documents semantic gaps, representation mismatches, and potential information loss when transforming between SDMX and DPM (and XBRL serialisation).

It aims to:
- Provide a systematic inventory of gaps across glossary, data definition, and organisational layers.
- Analyse critical semantic gaps that require conventions or mitigation strategies.
- Document specific gap areas: defaults/implicit dimensions, multi-measure handling, and temporal semantics.
