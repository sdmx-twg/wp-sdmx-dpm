# Versioning and Extensibility

This section documents how versioning and extensibility work in SDMX and DPM, highlighting their fundamental differences.

It aims to:
- Explain SDMX's uniform versioning model (all MaintainableArtefacts are versioned).
- Explain DPM's hybrid model: true versioning for Modules/Tables vs release-based change logs for glossary.
- Clarify the critical role of Module context in determining glossary applicability.
- Document extensibility patterns and compatibility considerations.
