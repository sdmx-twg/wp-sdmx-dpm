# Versioning and Extensibility

This section documents the **detailed, artefact-level** versioning and extensibility mapping rules for SDMX and DPM.

> **The conceptual overview now lives in the Basics chapter:** [Basics → Versioning Overview](../00_basics/03_versioning_overview.md). Versioning is a foundational, horizontal topic, so the high-level explanation of how SDMX versions and DPM releases work has been moved early in the documentation. This chapter holds the detailed mapping rules and extensibility patterns that build on it.

It aims to:
- Document extensibility patterns and compatibility considerations.
- Provide the artefact-level mapping rules for Organisations, Releases, Deactivation, and the Annotation extension mechanism.
